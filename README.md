# SELETA · Pães e Confeitaria

Landing page da SELETA Pães e Confeitaria — Comercial Alpha Center, DF-140, Jardim Botânico, Brasília.

Site estático (HTML, CSS e JavaScript puros, sem build). Para ver localmente, abra o `index.html` no navegador.

## Estrutura

```
index.html        página completa (estilos e scripts embutidos)
assets/           imagens em WebP + logo
```

## Seções

- **Hero** — menu fixo e slider em tela cheia (pães, pizzas, frango assado).
- **Cardápio** — abas por categoria, destaques e pedido pelo WhatsApp.

## Identidade visual

| Token | Cor | Uso |
|---|---|---|
| Creme | `#F7F2E8` | fundo principal |
| Papel | `#FFFCF6` | fundo de apoio |
| Trigo | `#E8D7B7` | superfícies secundárias |
| Dourado | `#C69B52` | filetes e pequenos acentos |
| Mel tostado | `#75501E` | CTA e links |
| Carvão | `#25211B` | texto principal |

Tipografia: **Cormorant Garamond** (títulos) e **Work Sans** (texto e interface), via Google Fonts.

Largura máxima do conteúdo: `--container: 1280px`.

## Imagens pendentes do cardápio

Formato vertical 4:5, mínimo 1200×1500 px, em WebP:

- `assets/cardapio-confeitaria.webp`
- `assets/cardapio-salgados.webp`
- `assets/cardapio-cafes.webp`

Enquanto não existirem, o cardápio mostra um espaço reservado no tom trigo.
